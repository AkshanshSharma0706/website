## Initial prompt (five parts)
**Role:** You are a senior full-stack developer and UX designer.
**Task:** Build a career guide website with a career explorer, a 5-question interest quiz, step-by-step career roadmaps and a working AI chatbot.

**Constraints:** HTML, CSS and vanilla JavaScript only. Chatbot calls a Vercel serverless function `/api/chat` that calls the Gemini API; the key lives in an environment variable. Mobile-friendly. Handle empty input and API errors.
**Output Format:** File tree first, then each file in its own code block, then run and deploy steps.
